# Source assets

The client supplied `VeloreLogo.jpeg` during this task. The original file is preserved unchanged at `assets-source/VeloreLogo.jpeg` and is not served by the website. Run `pnpm brand:assets` to create the transparent PNG lockup, monogram and wordmark, plus favicon, apple-touch icon and Open Graph image. The crop boxes target this 1254 × 1254 logo composition. The outputs remain raster extractions; replace them with client-provided vector SVGs if available later.
